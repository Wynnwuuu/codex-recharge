# 参考视频与复刻取舍

参考片段为 [Motionface · Primium Recharge Overlay](https://motionface.cc/?recording=610805bb-4a78-484b-b37c-916aa34bbee6)，片段 ID 为 `610805bb-4a78-484b-b37c-916aa34bbee6`。本地分析的视频为 720 × 720、60 fps、约 15 秒。参考文件仅用于逐帧观察，不随仓库发布。

## 构图与材质

白色方形画布中，深色圆角卡片居中，占画布宽度约 68%。卡片顶部是白色粗体无衬线标题，中部有低对比度的 `0 / 50 / 100` 刻度，下半部为宽胶囊形电量槽。低电量使用红橙色，充满时变为绿色与荧光黄渐变。槽体有玻璃高光、细轮廓和柔和光晕，卡片底部有随电量变色的投影；液面边缘持续轻微摆动。

实现使用内联 SVG 的圆角矩形、路径、渐变、模糊滤镜及低对比度点阵纹理。字体采用本机 Arial / Helvetica 无衬线回退；未能从视频确认原始字体文件，因此字形为近似还原。

## 节奏

| 参考时间 | 观察与实现 |
| --- | --- |
| 0–1.25 秒 | 红色低电量，约 20%，液面轻微摆动 |
| 1.25–2.5 秒 | 电量迅速升高，红橙经过黄色转为绿色 |
| 2.5–8.2 秒 | 绿色满电量停留，维持发光与细微运动 |
| 8.2–10 秒 | 电量下降，颜色逐渐回到橙红 |
| 10–15 秒 | 回到约 20% 的低电量状态，衔接循环 |

时间点来自关键帧观察，为近似值。进退使用平滑插值，波动由帧号驱动，渲染不依赖真实时间。画面本身没有场景切换；主要转场是液面位移、颜色和光晕变化。
