# 本机数据与公开源码

本项目在本机读取 Codex 状态，界面只需要剩余用量、额度窗口、更新时间和运行任务数量。公开仓库不包含个人账号状态、会话记录、参考视频、签名下载地址或 Motionface 绑定凭证。

## 访问范围

- 用量通过已有本机 Codex 程序启动 app-server，再调用 `account/rateLimits/read`。登录和账号服务连接由 Codex 自己管理；本项目不把 token 写入前端或仓库，也不调用重置额度、购买 credits 或发送消息的方法。
- 运行任务统计只读访问本机 Codex 的 `thread_history_*.sqlite` 和 `state_*.sqlite` 中的状态元数据，并检查 writer lock。查询字段用于判断根会话是否仍在运行，不读取任务标题、消息正文或认证文件，返回结果只包含数量和读取状态。
- 桌面宿主只接受打开 Codex、请求状态、拖动以及界面布局和悬停测量所需的受限前端操作。界面加载应用包内资源；开发服务器默认仅绑定 `127.0.0.1`。

悬停检测在本机读取当前鼠标位置，以可见圆角卡片的边界判断是否显示提示；不记录鼠标轨迹，也不上传鼠标坐标。

## 本机写入

依赖写入项目的 `node_modules/`，构建与渲染写入 `dist/`、`work/` 和 `outputs/`。桌面版的运行缓存位于 macOS 当前用户临时目录的 `cc.motionface.codex-recharge/` 子目录；macOS 保存悬浮窗位置。它不会写入 Codex 配置、修改会话、添加开机启动项或把状态上传到本项目的服务器。

`.gitignore` 排除生成文件、环境变量、日志及视频文件。使用者仍应在发布源码前检查暂存内容；不要把个人用量截图、生成的实时视频或缓存当成通用示例提交。

本工具依赖本机 Codex 版本与状态格式；读取失败会返回不可用，旧用量快照会显式标记为旧数据。它不提供跨设备任务统计。
